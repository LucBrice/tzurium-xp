# TZURIUM XP — EBTA engine (public snapshot)

This repository is a public, sanitized snapshot of the `ebta_engine` core
from the EBTA (Evidence-Based Technical Analysis) project — the
statistical/governance engine that mechanically enforces the rules
described by Aronson's Evidence-Based Technical Analysis methodology.

Licensed under the Apache License, Version 2.0 — see `LICENSE` and
`NOTICE`.

This snapshot is derived from a private development repository via a
manifest-driven, fail-closed export process. It contains only the files
classified as publishable ("code seulement" — `Implementation/ebta_engine/`)
by that manifest; strategy-specific and adapter code remain private.
